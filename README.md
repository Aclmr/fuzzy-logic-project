## Original Paper
T. Salameh, M. M. Farag, A.-K. Hamid, M. Hussein, "Adaptive neuro-fuzzy inference system for accurate power
forecasting for on-grid photovoltaic systems: A case study in Sharjah, UAE," *Energy Conversion and
Management: X*, vol. 26, p. 100958, 2025. doi: [10.1016/j.ecmx.2025.100958](https://doi.org/10.1016/j.ecmx.2025.100958)

## Problem Description
PV output depends non-linearly on weather. The paper estimates the DC **power, voltage and current** of a
grid-connected PV system from four environmental measurements (solar irradiance, ambient temperature, module
temperature, wind speed) using ANFIS, and compares it with Linear Regression, Decision Tree, SVM and Random Forest.

## Method
- First-order **Takagi–Sugeno** ANFIS, one model per output (3 models).
- **Gaussian** membership functions, **product** T-norm, weighted-average defuzzification.
- Rule base generated by **subtractive clustering** (4 rules, as in Table 1 of the paper).
- **Hybrid learning:** least-squares for consequent parameters + gradient descent (Adam) for MF centres/widths.
- Implemented from scratch in NumPy (`src/anfis.py`); no external fuzzy/ANFIS library is used.

## Fuzzy System Architecture
```
x = [irradiance, T_amb, T_module, wind]
 L1  Fuzzification      mu_ij(x_i) = exp(-(x_i - c_ij)^2 / (2 s_ij^2))
 L2  Rule firing         w_j = prod_i mu_ij(x_i)                     (product AND)
 L3  Normalisation       wbar_j = w_j / sum_k w_k
 L4  Rule output         wbar_j * (p_j x1 + q_j x2 + r_j x3 + s_j x4 + t_j)
 L5  Output              y = sum_j wbar_j f_j                         (weighted average)
```

## Dataset
The paper's Sharjah data is not public ("available on request"). We use the openly licensed
**NIST Ground Array** dataset (Gaithersburg, MD, USA), which measures exactly the same 4 inputs and 3 outputs:

| Paper variable | NIST column |
|---|---|
| Solar irradiance | `RefCell1_Wm2_Avg` (plane-of-array reference cell) |
| Ambient temperature | `AmbTemp_C_Avg` |
| Module temperature | mean of back-of-module RTDs `RTD_C_Avg(1..9)` |
| Wind speed | `WindSpeedAve_ms` |
| DC voltage / current / power | `InvVDCin_Avg` / `InvIDCin_Avg` / `InvPDC_kW_Avg` |

Preparation (`src/prepare_nist.py`): June–September 2017 (same season as the paper), 1-min data averaged to
hourly, night hours removed (irradiance ≤ 20 W/m²) → `data/nist_hourly.csv` (1557 rows). `src/data.py` removes
2 physically inconsistent hours (P ≠ V·I, inverter outage) → 1555 rows, split randomly 68.2 % / 31.8 %
(the paper's 410/191 ratio) with seed 42.

To rebuild the CSV from raw data: download Ground → OneMin → "1-min avg." for 2017-06…2017-09 from
<https://pvdata.nist.gov>, put the files in a folder and run `python src/prepare_nist.py <folder> data/nist_hourly.csv`.

## Reproduction Experiments
**Experiment 1 — ANFIS accuracy for each output (paper Table 4)**

| Output | Paper train R² | Ours train R² | Paper test R² | Ours test R² |
|---|---|---|---|---|
| DC power | 0.9908 | 0.9959 | 0.9967 | 0.9952 |
| DC voltage | 0.9000 | 0.9501 | 0.9076 | 0.9490 |
| DC current | 0.9912 | 0.9957 | 0.9913 | 0.9949 |

**Experiment 2 — DC power, ANFIS vs ML models (paper Table 5).** RMSE is in W for very different system
sizes (2.88 kW vs. ~270 kW), so test RMSE is also given as % of mean power (nRMSE).

| Model | Paper test R² | Ours test R² | Paper test nRMSE % | Ours test nRMSE % |
|---|---|---|---|---|
| Linear Regression | 0.9380 | 0.9888 | 14.7 | 6.7 |
| Decision Tree | 0.9358 | 0.9902 | 15.0 | 6.2 |
| SVM | 0.9373 | 0.9941 | 14.8 | 4.8 |
| Random Forest | 0.9286 | 0.9944 | 15.8 | 4.7 |
| **ANFIS** | **0.996** | **0.9952** | **12.2** | **4.4** |

The paper's main finding is reproduced: ANFIS has the lowest test error (it ranked first in 10/10 random splits),
and voltage is the hardest output to predict.

## Limitations
- Different site and climate (temperate Maryland vs. hot-arid Sharjah) and a much larger array.
- The paper does not report the clustering radius, epochs, split procedure or ML hyper-parameters; we chose the
  radius that yields 4 rules, 100 epochs, a seeded random split and scikit-learn defaults.
- The task is same-time estimation from weather, not forecasting ahead in time (as in the paper).
